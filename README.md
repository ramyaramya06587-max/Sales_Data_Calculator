# Sales Data Calculator

## Project Overview
The Sales Data Calculator is a Python-based data analysis project developed as part of Task 4 of the Artificial Intelligence and Machine Learning (AI & ML) internship at Veda Technology.

The project analyzes a sample sales dataset and calculates important sales statistics using Python's built-in functions.

## Objectives
- Calculate total sales.
- Calculate average sales.
- Identify the highest sale.
- Identify the lowest sale.
- Present the results in a clear and organized report.

## Technologies Used
- Python
- Jupyter Notebook
